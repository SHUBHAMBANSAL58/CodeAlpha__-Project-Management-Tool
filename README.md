# Project_Management_Tool

A project management application for creating projects, assigning tasks, setting deadlines, and tracking progress.

## 🎯 Project Overview

A web-based tool designed to simplify project and task management.

## 📦 Features

* Create and manage projects
* Assign tasks to team members
* Set deadlines and priorities
* Track task progress
* Dashboard for project monitoring
* Responsive user interface

## 🛠️ Technologies

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Deployment:** Netlify
